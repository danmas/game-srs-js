# Журнал изменений и прогресса разработки

Этот файл содержит краткое описание основных доработок, исправлений и добавленных функций.

## Сессия от 04.11.2025

### Ключевые изменения:

1.  **Создание и отладка тестового сценария (`Scenario_test_1.ts`)**
    -   Создан новый сценарий для изолированного теста боя между AI-объектами ("Kashin" vs "Hunter").
    -   Из сценария удалены объекты игрока и элементы карты (побережье) для симуляции боя в открытом море.
    -   Исправлена логика завершения игры (`checkGameOver`) для корректной работы сценария без игрока.

2.  **Внедрение и отладка системы DSL-стратегий**
    -   Реализован парсер и исполнитель для DSL (Domain-Specific Language) на основе YAML, позволяющий описывать AI-стратегии в декларативном стиле.
    -   В тестовый сценарий добавлена DSL-стратегия "Агрессивный охотник" для подлодки "Hunter".
    -   **Отладка AI**:
        -   Добавлено расширенное логирование (`DEBUG` уровень) в `DSLParser` и `DSLStrategy` для отслеживания хода выполнения логики AI (оценка условий `IF/ELSE`, выполнение действий `ATTACK`, `CHASE`).
        -   Исправлена синтаксическая ошибка в условии DSL (`distance_to(best_target)`).
        -   Оптимизированы параметры DSL-стратегии (дистанция атаки, упреждение, дистанция преследования).

3.  **Исправление системных ошибок**
    -   **Проблема со сборкой проекта**: Выявлено и исправлено, что изменения в коде не применялись из-за отсутствия пересборки проекта. Внедрен процесс `npm run build` после внесения изменений.
    -   **Ошибка импорта `LogLevel`**: Устранена ошибка компиляции, связанная с неправильным импортом `LogLevel` в модулях DSL.
    -   **Циклическая зависимость**: Обнаружена и исправлена критическая ошибка `Cannot access 'p' before initialization`, вызванная циклической зависимостью между `AIStrategyFactory` и другими модулями. Восстановлена "ленивая" загрузка DSL-стратегии через `require`.

4.  **Актуализация документации**
    -   Создан новый файл `README_LLM_ANALYSIS.md`, содержащий исчерпывающую документацию по DSL, формату логов и ключевым механикам игры для анализа сторонними LLM.
    -   Обновлены существующие `README.md`, `README_GAME_AI.md` и `README_AI_STRATEGIES.md` для отражения новой системы DSL-стратегий и актуальной структуры проекта.
    -   Удалена дублирующаяся документация.

## Сессия от 22.05.2025

**Что реализовано в этой версии:**
- Искусственный интеллект противника может производить выстрелы.

**Известные недостатки:**
- Не реализована зона видимости:
  - Цели считаются видимыми без учёта дистанции/препятствий.
  - Противник видит игрока с самого начала игры.
- Отсутствует "шумность целей" (например, нет погрешности в прицеливании или вероятности промаха).
- Вражеский корабль начинает стрелять сразу после старта игры.
