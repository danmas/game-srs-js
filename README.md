# Silent Red Storm

Симулятор подводной войны, портированный с ActionScript на JavaScript/TypeScript.

## Описание

Silent Red Storm (SRS) - это симулятор подводных лодок с элементами морского боя. Игра предоставляет возможность управлять подводной лодкой, обнаруживать противников по шуму, атаковать торпедами и маневрировать для уклонения от вражеских атак.

## Технологииd

- TypeScript
- Phaser.js для графики и игровой механики
- Webpack для сборки
- Socket.io для мультиплеера (в будущих версиях)

## Установка и запуск

### Требования

- Node.js (версия 14 или выше)
- npm (версия 6 или выше)

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

Существует два основных способа запустить игру в режиме разработки:

**Способ 1: Использование webpack-dev-server (рекомендуемый)**

Этот способ автоматически собирает проект, запускает веб-сервер и перезагружает страницу в браузере при изменениях в коде.

В директории `game-srs-js` выполните:
```bash
npm start
```
Игра обычно становится доступна по адресу `http://localhost:8080` (точный адрес будет указан в консоли).

**Способ 2: Ручная сборка и запуск статического сервера**

Этот способ подходит, если вам нужен больший контроль над процессом или если `webpack-dev-server` по какой-то причине не работает.

1.  **Сборка проекта:**
    В директории `game-srs-js` выполните команду для сборки проекта в режиме разработки. Эта команда также будет следить за изменениями в файлах и автоматически пересобирать проект:
    ```bash
    npm run dev
    ```
    Собранные файлы появятся в папке `game-srs-js/dist/`.

2.  **Запуск HTTP-сервера:**
    После успешной сборки, не закрывая терминал, где выполняется `npm run dev` (или в новом терминале), перейдите в директорию `game-srs-js` и запустите статический HTTP-сервер, указав ему папку `dist` и порт (например, 8084):
    ```bash
    npx http-server ./dist -p 8084
    ```
    Или, можно сначала перейти в папку `dist` и запустить сервер оттуда:
    ```bash
    cd dist
    npx http-server -p 8084
    ```
    После этого игра будет доступна по адресу `http://localhost:8084`.

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут находиться в директории `dist/`.

## Управление

- Цифровые клавиши `0-6` - выбор мощности двигателя.
- `S` - старт/остановка игры.
- `A` или `Стрелка Влево` - поворот влево.
- `D` или `Стрелка Вправо` - поворот вправо.
- `Ctrl + Левая кнопка мыши` - установить новую путевую точку (WP) или удалить существующую WP при клике на нее.
- `Правая кнопка мыши` - отображение подсказки по установке WP.
- `Escape` - отмена текущего выбора оружия или режима прицеливания.
- `U` - всплытие (для подводных лодок).
- `D` - погружение (для подводных лодок).
- `P` - поднять/опустить перископ (для подводных лодок).
- `Q` - выбор торпеды типа I и вход в режим прицеливания (ЛКМ/Enter для выстрела, ПКМ/Esc для отмены).
- `W` (при выборе оружия, если не в режиме прицеливания) - выбор торпеды типа II (по старому интерфейсу, требует клика для цели).
- `E` (при выборе оружия, если не в режиме прицеливания) - выбор торпеды типа III (самонаводящейся, требует клика для цели).
- `Z` - отдалить карту.
- `X` - приблизить карту.
- `C` - центрировать камеру на корабле игрока.
- `Tab` - выбрать корабль игрока и центрировать камеру.
- `Ctrl + B` - показать/скрыть панель отладки.

### Основные Темы

- **DSL для AI**: Создание сложных стратегий поведения с помощью простого YAML-синтаксиса.
- **Система Координат**: Игра использует НАВИГАЦИОННУЮ систему (0° = вверх), а НЕ математическую (0° = вправо).
- **Разработка AI Стратегий**: Создание пользовательских стратегий через систему "Сменных Мозгов" на TypeScript.
- **Физика и Движение**: Инерция, руление, мощность двигателя.
- **Обнаружение Целей**: Система на основе шума, 3 зоны обнаружения
- **Управление Оружием**: Типы торпед, прицеливание, упреждение
